SPI

$250

Synchronous High-Speed

• ซิงโครนัส: ใช่
• จำนวนสาย: 3 (MOSI, MISO, SCLK) + SS
• Master/Slave: ใช่
• ความเร็ว: เร็วที่สุด
• Addressing: ไม่มี (ใช้สาย SS)
💡 เหมาะกับการส่งข้อมูลปริมาณมาก เช่น TFT Display / SD Card

I2C

$180

Synchronous 2-Wire Bus

• ซิงโครนัส: ใช่
• จำนวนสาย: 2 (SDA, SCL)
• Master/Slave: ใช่ (Multi-Master)
• ความเร็ว: ปานกลาง
• Addressing: มี (7-bit/10-bit)

สรุปความแตกต่างสำหรับการสื่อสารข้อมูลแบบอนุกรมในไมโครคอนโทรลเลอร์

🔹 ซิงโครนัส vs อะซิงโครนัส

ซิงโครนัส (SPI, I2C): มีสายสัญญาณ Clock (SCLK/SCL) ส่งกำกับการรับส่งข้อมูล ทำให้รับส่งได้แม่นยำและเร็วกว่า
อะซิงโครนัส (UART): ไม่มีสาย Clock ต้องตั้งค่า Baud Rate ของผู้รับและผู้ส่งให้ตรงกันล่วงหน้า

🔹 Addressing (การระบุตำแหน่ง)

I2C: มี Hardware 7-bit Address ในการจ่าหน้าเรียกชื่ออุปกรณ์ จึงพ่วงหลายตัวบนสาย 2 เส้นได้
SPI: ไม่มี Addressing แต่ใช้วิธีลากสาย Chip Select (SS) แยกทีละเส้นแทน
